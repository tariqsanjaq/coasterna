## 4. All-routes terminology

`lib/features/search/presentation/all_routes_screen.dart`, `_subtitleFor()`
(lines 310–314):

```dart
String _subtitleFor(RouteModel route) {
  final operatorName = route.operatorName.trim();
  if (operatorName.isNotEmpty) return operatorName;
  return '${route.originStopName} to ${route.destinationStopName}';
}
```

The origin/destination label uses `"to"` as the separator (line 313), not
`"->"`. Note this line is a **fallback only** — used when
`route.operatorName` is blank; when an operator name is set, that renders
instead (per the doc comment above `_subtitleFor`, lines 307–309).
